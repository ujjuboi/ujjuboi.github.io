# Getting into AI/ML Agents

**Date:** February 17, 2026

**Excerpt:** My journey from writing scripts to building autonomous AI agents — the tools, frameworks, and lessons learned along the way.

**Banner:** ../../Images/Graphics/Mind.svg

**Category:** Research

Artificial Intelligence has always fascinated me, but it wasn't until I started working with Large Language Models (LLMs) that I truly understood what 'intelligence' in a machine could mean. The concept of agents — systems that can reason, plan, and act autonomously — is reshaping how we think about software.

My entry into this space began with LangChain, which provided the perfect abstraction for connecting LLMs with external tools and data sources. I built my first agent: a research assistant that could search the web, extract information from documents, and synthesize findings into structured reports.

The agent framework revolves around three components: the LLM engine (which I've experimented with using Claude, Codex, and various local models), the tool execution layer (which handles API calls, file operations, and web fetching), and the orchestration layer (which breaks down complex tasks into manageable sub-plans).

One of the most impactful projects I've built is an AI-powered code workflow system using GitHub Actions. The agent reviews pull requests, checks for maintainability issues, generates documentation, and even creates test cases — all autonomously. The key lesson I learned was that guardrails are just as important as capabilities; an agent without proper constraints can cause as much harm as it can help.

The future of software engineering will involve human-AI collaboration, not human-AI competition. I'm excited to keep building in this space and learning from the rapidly evolving agent ecosystem.
